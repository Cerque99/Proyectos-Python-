# Proyectos y Ejercicios en Python 🐍

¡Hola! Bienvenido/a a mi repositorio de desarrollo en Python. 

Aquí documento mi código y las soluciones a diversos problemas de programación. El objetivo de este repositorio es mostrar mi capacidad para escribir código limpio, aplicar estructuras de control de flujo, manejar excepciones y resolver problemas complejos mediante el desarrollo de software.

## 📌 Sobre los proyectos
Los ejercicios incluidos en este repositorio han sido desarrollados como parte del curso **CS50’s Introduction to Programming with Python (CS50P)** de la Universidad de Harvard. 

Con una fuerte base de formación matemática, utilizo estos proyectos para trasladar el razonamiento lógico y analítico a la programación, preparándome para aportar valor en entornos corporativos orientados al análisis de datos y la tecnología.

## 📂 Ejercicios destacados
Algunos de los retos de código que encontrarás en las carpetas incluyen:
* **Procesamiento de datos y cadenas:** Manipulación y limpieza de strings (ej. `twttr`, `camel`).
* **Lógica matemática y bucles:** Creación de algoritmos para cálculos iterativos (ej. `coke`, `nutrition`).
* **Validación de reglas y formatos:** Comprobación de requisitos lógicos estrictos (ej. `plates`).

## 🛠️ Tecnologías y Herramientas
* **Lenguaje:** Python 3
* **Entorno:** Visual Studio Code / GitHub Codespaces
